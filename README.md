# The Tower, um simples jogo de labirinto
Gênero: Puzzle

Objetivo: Coletar todas as chaves do labirinto, e desviar dos inimigos

## Alunos:
 - Gustavo Lima Jatobá Leite
 - José Lucas dos Santos Ferreira
 - Enrico Dias França
 - Arthur Vieira Rodrigues

## Algorítimos usados:
 - AStar: Usado para o pathfinding dos inimigos
 - Merge Sort: Usado para organizar o inventário
 - TSP: Usado para calcular a rota mínima

## Como jogar:
É só baixar os arquivos do repositório, e então rodar o index.html
